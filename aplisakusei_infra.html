低コストインフラで作る
無料枠を活用したコスパ重視の構成

基本方針

個人開発や小規模プロジェクトでは、大規模なクラウドインフラは不要です。
無料プランや低価格サービスを組み合わせることで、月額0円〜数百円でアプリを公開・運用できます。

「まず出す、使われたらスケールする」の精神で、最小構成からスタートします。

GitHub

用途 ソースコード管理 / CI・CD / ホスティング（GitHub Pages）
費用 無料（パブリックリポジトリ無制限、プライベートも無料）
メリット GitHub Actionsで自動デプロイ、GitHub Pagesで静的サイト公開が無料

Cloudflare

用途 CDN / DNS / SSL / Webホスティング（Cloudflare Pages）
費用 無料（Freeプランで十分な機能）
メリット 高速なCDN配信、無料SSL、DDoS対策、Cloudflare Pagesでフロントエンドのホスティングも無料

Supabase

用途 データベース（PostgreSQL） / 認証 / ストレージ / リアルタイムAPI
費用 無料（Freeプラン：500MB DB、1GB ストレージ、50,000 MAU）
メリット Firebaseの代替としてオープンソース。PostgreSQLベースなので柔軟性が高い。認証・ストレージ・APIが一体で楽

Google Play Store

用途 Androidアプリの配信
費用 初回登録料 $25（約3,500円）のみ。以降は無料
メリット 一度払えば永久にアプリ公開可能。アップデートも無料

Apple App Store

用途 iOSアプリの配信
費用 年額 $99（約15,000円）/ Apple Developer Program
メリット iPhoneユーザーにリーチできる。TestFlightでベータ配信も可能

構成例と月額コスト

Webアプリの場合

フロントエンド Cloudflare Pages 0円
バックエンド・DB Supabase Free 0円
ソース管理・CI/CD GitHub 0円
合計 月額 0円

モバイルアプリの場合

バックエンド・DB Supabase Free 0円
Android配信 Google Play 初回3,500円のみ
iOS配信 App Store 年15,000円
合計 ランニングコストほぼ0円（ストア費用除く）

まとめ

大手クラウド（AWS/Azure/GCP）を使わなくても、個人開発レベルなら無料サービスの組み合わせで十分に運用できます。

  • ユーザーが増えてきたらSupabaseのProプラン（$25/月）に上げる
  • アクセスが増えたらCloudflare Workersでサーバーレス処理を追加
  • 必要になったタイミングでスケールすればOK

「最初から大きく構えない。小さく始めて、必要に応じて育てる」がコスパ最強のインフラ戦略です。
